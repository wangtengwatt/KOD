# 第三批实施计划：本地助手业务闭环

## 当前基线确认

当前工作区已经完成确认草案、独立气泡会话和共享实体类型，但确认按钮仍是占位：它只显示“草案已准备”，没有创建任何实体。第三批将把这条链路变成可持久、幂等、可恢复的确定性执行系统。

保留现有与本任务无关的 `docs/README.md` 删除和 `.zcode/` 文件，不回退、不覆盖。

## 1. 收紧领域契约

扩展 `src/shared/types/suanbao.ts`：

- 为确认卡增加结构化 `action` payload，不再从 `fields[].label/value` 反向解析业务数据；
- 定义四类动作：创建待办、创建提醒、启动番茄钟、创建本地日程；
- 为 Operation 增加 `idempotencyKey`、`resultEntityId` 和必要的执行错误字段；
- 为提醒、番茄和本地日程补齐 `createdAt`、`updatedAt`、完成/触发时间及 revision 等恢复字段；
- 增加 Create/Update 输入类型、查询过滤类型和合法状态迁移纯函数；
- 改造 intent parser，使其生成可执行的结构化 payload；确认字段只承担展示。

幂等语义采用“每个确认草稿一个随机稳定 key”：同一次确认的双击/重试沿用 key；用户重新发起内容相同的操作生成新 key，因此允许创建两个相同待办。

## 2. 建立 SuanbaoRepository

新增：

```text
src/renderer/packages/suanbao/repositories/SuanbaoRepository.ts
src/renderer/packages/suanbao/repositories/IndexedDBSuanbaoRepository.ts
src/renderer/packages/suanbao/repositories/MemorySuanbaoRepository.ts
src/renderer/packages/suanbao/repositories/createSuanbaoRepository.ts
```

本批先完成可运行的 IndexedDB 与 Memory 实现；SQLite adapter 的共享接口和 schema 保留，但不在缺少可复现移动原生工程时声称真机完成。

Repository 按账户使用独立数据库：`kod-suanbao-<accountKey>`，包含 stores：

- `operations`
- `todos`
- `reminders`
- `pomodoros`
- `local-calendar-events`

索引：

- operation：status、updatedAt、唯一 idempotencyKey；
- todo：completed、dueAt、updatedAt；
- reminder：status、triggerAt；
- pomodoro：status、updatedAt；
- calendar：startsAt、endsAt。

接口覆盖：初始化/关闭、四类实体 CRUD、active pomodoro 查询、due reminder 查询、operation CRUD/按幂等键查询、clear/delete database。

关键事务：确认执行时在同一 IndexedDB readwrite transaction 内完成 operation claim、实体写入、operation succeeded/resultEntityId 写入。重复 confirm 直接返回已有结果，不重复创建实体。

## 3. 业务服务

新增以下确定性服务：

### TodoService

- 创建、查询、更新、完成/取消完成、删除；
- trim 和非空校验；
- 自动维护 createdAt/updatedAt。

### LocalCalendarService

- 创建、查询范围、更新、删除；
- 校验标题、有限时间和 `endsAt > startsAt`；
- 与系统日历模型完全分离，不请求系统权限。

### PomodoroService

实现状态机：

```text
none -> running
running -> paused | completed | cancelled
paused -> running | cancelled
completed(work) -> 可启动 break
completed(break) -> 可启动 work
```

- running 的事实是 `endsAt`；
- pause 保存 `remainingMs`；
- resume 以 `now + remainingMs` 生成新 endsAt；
- 不每秒持久化；
- 同一账户只允许一个 running/paused 番茄；
- `reconcile(now)` 在重启后恢复或幂等完成已到期会话。

### ReminderService / Scheduler

- 提醒持久化以 `triggerAt` 和 status 为事实；
- 前台 scheduler 只维护最近提醒的一个 timer；
- 创建、修改、取消后重排；
- 初始化、visibility 恢复、窗口 focus/show 后调用 `reconcile(now)`；
- 一次性过期提醒恢复时触发一次；daily/weekly 只推进到下一个有效周期，不补发所有错过周期；
- timer 只是唤醒手段，到期始终重新比较 `Date.now()`；
- 本批先发布应用内 reminder activity，并保留系统通知 adapter 端口，Desktop 主进程通知归后续 Electron 批次接线。

## 4. OperationService 与确认执行器

新增：

```text
src/renderer/packages/suanbao/operationService.ts
src/renderer/packages/suanbao/confirmationExecutor.ts
src/renderer/packages/suanbao/runtime.ts
```

流程：

```text
intent parser
 -> prepare(confirmation/action)
 -> 持久化 awaiting-confirmation operation
 -> UI 展示

confirm(operationId)
 -> 原子 claim running
 -> 按 action.kind 执行
 -> 写实体和 succeeded/resultEntityId
 -> 发布 success activity

cancel(operationId)
 -> awaiting-confirmation -> cancelled
```

行为规则：

- succeeded 重复确认返回相同 result，不再执行；
- cancelled 拒绝执行；
- failed 只有显式 retry 才重跑；
- 账户切换后旧 operation 不可在新账户执行；
- 失败必须写入 failed/errorCode，UI 不显示伪成功；
- 运行中/确认中状态通过统一 Activity 发布，不继续堆在 React 本地 state。

## 5. UI 真正接线

修改 `SuanbaoPet.tsx`：

- 本地意图产生 confirmation 时先调用 `operationService.prepare()`；
- 确认卡读取持久化 operation；

- 组件重新挂载时恢复最近 awaiting-confirmation operation；
- 订阅统一 activity，让确认执行、番茄和提醒驱动宠物状态；
- 修复当前模型取消按钮的 operationId 时序问题，但不把 CRUD 写进组件。

必要时抽出 `SuanbaoConfirmationCard`，保持主组件可读。

## 6. Runtime 初始化和恢复

在根应用初始化完成后启动一次 account-scoped Suanbao runtime：

- 初始化当前账户 Repository；
- 恢复最近 awaiting-confirmation operation；
- 恢复 active pomodoro；
- reconcile reminders 和已过期番茄；
- 监听账户切换：先停止 timer/关闭旧 repository，再初始化新账户；
- 监听 `document.visibilitychange`；Desktop 再接已有 `onWindowFocused/onWindowShow`；
- 所有入口调用同一可重入 `reconcile()`，重复事件不重复触发。

## 7. 测试范围

### Repository 合约

Memory 和 IndexedDB 共用测试套件：

- 四类实体 CRUD、排序和范围查询；
- guest/账户 A/账户 B 隔离；
- operation 状态持久化；
- 并发双击 confirm 只创建一个实体；
- transaction 中途失败不保留半成品；
- clear 与 delete database；
- close 后重新初始化。

### 状态机与恢复

- Operation 所有合法/非法迁移；
- Todo 完成/编辑/删除；
- Calendar `endsAt <= startsAt` 拒绝；
- Pomodoro start/pause/resume/cancel/complete；
- 重启时 running 未到期恢复；已过期只完成一次；paused 不自动恢复；
- Reminder 新增/取消/过期补偿/daily/weekly；
- 多次 reconcile 不重复 fire；
- 系统时间前后跳和长 timeout 分段。

### UI/集成

- 未确认时绝不创建实体；
- 取消后不执行；
- 确认后展示真实实体结果；
- 双击确认幂等；
- 执行失败保留可理解错误；
- remount 恢复 awaiting confirmation。
