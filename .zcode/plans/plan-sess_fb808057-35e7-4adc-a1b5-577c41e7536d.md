# 首批公开 MVP：第一轮回归修复实施计划

## 范围与原则

先处理用户当前能直接看到的 P1 回归，不马上进入备份恢复或云同步。本批目标是：

1. 新安装默认简体中文，已有明确语言选择保持不变。
2. 主窗口在所有顶层页面和全屏设置界面始终有可用的窗口控制按钮。
3. 独立蒜宝窗口悬停/键盘聚焦时显示最小化与关闭按钮；最小化进入任务栏，关闭只隐藏并可由托盘恢复。
4. 保留当前桌宠 Runtime 加固、严格 preload 边界和位置持久化。
5. 完成后运行定向测试、类型检查、Biome 和生产构建，再单独提交推送。

当前工作树存在一批与蒜宝无关、尚未提交的 Tinpay/深链改动，并与 `main.ts`、preload、Electron 类型等文件重叠。实施时不覆盖、不删除这些改动；在写入重叠文件前先保存其当前内容并做最小合并，提交时只暂存本批蒜宝/语言修复的明确文件或补丁。

## 1. 修复全局语言默认值和迁移

### 1.1 单一语言来源

- 将 `src/shared/defaults.ts` 的新安装默认语言改为 `zh-Hans`。
- 将 settings persist 版本从 4 升到 5。
- 在合并默认值前检查原始持久化对象是否拥有合法 `language` 字段：
  - 合法且明确存在：保持 `en`、`zh-Hant` 或其他用户选择。
  - 缺失或非法：迁移为 `zh-Hans`。
- 不再使用 `languageInited` 判断用户是否明确选择过语言。

### 1.2 移除启动后覆盖

- 停止在根路由调用延迟两秒的 `useSystemLanguageWhenInit()`。
- 保留 locale parser 供真正需要“跟随系统”的功能使用，但不再让它覆盖产品默认语言。
- i18next 启动默认和 fallback 对齐 `zh-Hans`，之后仍由 hydration 后的明确设置覆盖。

### 1.3 测试

扩充 settings persistence 测试：

- 无设置 → `zh-Hans`。
- 旧版本且无 language → `zh-Hans`。
- 明确 `en` → 保留 `en`。
- 明确其他合法语言 → 保留。
- 有 language 但无 `languageInited` → 仍保留。
- 非法 language → 安全回退 `zh-Hans`。

## 2. 恢复主窗口全局控制区

根因不是 Electron IPC 消失，而是主窗口是 `frame: false`，控制按钮却只挂在部分页面 Header；设置全屏 modal 等顶层界面没有控件。

### 2.1 全局挂载

- 在主 renderer 根 shell 增加唯一的 Windows/Linux `WindowControls` host，固定在右上层，并设置 `no-drag` 和足够 z-index。
- 让其覆盖普通路由、设置 modal、加载/错误界面。
- 移除或禁用 Header/Page/guide/task 中重复挂载，确保任何页面只出现一组按钮。
- 为顶部内容保留右侧空间，避免标题或操作按钮被覆盖。

### 2.2 行为与边界

- 继续复用现有 `window:minimize/maximize/unmaximize/close/is-maximized` 能力和 `useWindowMaximized()`。
- 若本批触及 main IPC，增加 sender-window 校验；不为主窗口新增不必要的通用权限。
- 验证 Windows/Linux 显示、macOS/Web/Mobile 不显示。

### 2.3 测试

- Windows/Linux 可见，其他平台隐藏。
- 最小化、最大化、恢复、关闭调用正确。
- 普通页面和 Settings modal 都有且只有一组控制区。
- 控件保留可访问名称与 no-drag 行为。

## 3. 独立蒜宝悬停控制按钮

### 3.1 最小权限 IPC

只为 pet preload 增加命名方法：

- `minimize(): Promise<void>`
- 继续复用 `hide(): Promise<void>` 作为关闭到托盘行为。

对应增加严格的共享 channel 和 pet-sender-only handler。不得暴露通用 `ipcRenderer.invoke`，不得把窗口控制混入 AI 业务命令。

### 3.2 BrowserWindow 状态

- 将 pet window 从 `skipTaskbar: true` 调整为可以进入任务栏，并启用最小化。
- `minimize()` 调用真实 BrowserWindow minimize。
- 托盘恢复时：若 minimized 先 restore，再 show/focus。
- hover“关闭”调用 hide，保持 `enabled=true` 和 Runtime/提醒运行。
- 增加关闭事件防御：非 app dispose/quit 时阻止真正销毁并隐藏；真正退出时允许 destroy。
- 明确区分 shown、hidden、minimized，避免把 minimized 误判为正常可见。
- 显式托盘“显示蒜宝”不得因为主窗口可见而静默失败；用户命令优先恢复独立窗口。

### 3.3 Renderer 与 CSS

- 在 `SuanbaoWindowApp.tsx` 增加两个独立按钮，不放入宠物拖拽按钮内部。
- `.suanbao-window:hover` 和 `:focus-within` 显示，默认隐藏。
- pointer down/click 阻止冒泡，不能开始拖动、切换气泡或误释放 pointer capture。
- 增加键盘焦点、ARIA label、disabled/error 处理。
- 调整窗口尺寸/布局以防控制区被透明窗口边界裁切，同时继续使用 placement clamp。

### 3.4 测试

- preload 只暴露批准的方法，minimize 映射到唯一 channel。
- main IPC 只允许 pet sender 最小化/隐藏。
- manager minimize、close-to-hide、dispose、tray restore、destroyed-window recreation。
- hover/focus 控件、防重复调用、不干扰拖动和气泡点击。
- Windows 手工验收任务栏最小化和托盘恢复。

## 4. 独立桌宠和主界面中文一致性

本批至少消除当前可见中英文混用：

- `SuanbaoRuntimeHost` 状态文案继续使用中文默认。
- 将语言加入受验证的 Suanbao bootstrap；独立窗口使用轻量 `zh-Hans/en` 字典，不加载完整主 renderer settings store。
- 本批若时间允许增加 bootstrap change 事件以支持设置页实时切换；否则必须确保窗口重建后正确读取当前语言，并把实时切换列为同批验收项，不留成隐含缺陷。
- 独立窗口的 Open KOD、隐藏、在线/离线、确认/取消、失败文案统一按语言显示。
- 后续再把管理页全部硬编码中文接入 i18n；由于英文仍为公开可选项，这项必须在公开灰度前完成，但不阻塞先修窗口回归。

## 5. 验证与提交

依次运行：

1. 新增/修改的定向 Vitest。
2. 定向 Biome，避免上次全目录误扫描 `node_modules` 引发 Windows 资源错误。
3. `NODE_OPTIONS=--max-old-space-size=8192 pnpm run check`。
4. Suanbao 相关测试集合。
5. `pnpm run build`。
6. Windows 手工检查：普通页、设置 modal、主窗口托盘恢复、宠物悬停控件、任务栏最小化、托盘恢复、关闭隐藏、多屏和 DPI。

提交策略：

- `.zcode/plans` 不提交。
- 不混入 Tinpay/其他未完成改动。
- 若重叠文件无法用路径级暂存隔离，使用补丁级暂存，并在提交前核对 staged diff。
- 本批验证通过后提交并推送到 `suanbao_KOD`，然后再进入提醒取消、番茄倒计时和备份恢复批次。
