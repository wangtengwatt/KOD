## Why

KOD 算力中心已经具备供应方认证、GPU 资质、商品图片、固定套餐购买、卡时冻结、交付、争议和 24 小时自动结算的基础能力，但这些能力没有形成可审计的托管交易闭环：管理员审核商品时看不到完整图片和关联资质，审核完成后记录从操作页消失；买卖双方没有订单内沟通和双方确认排期；已完成订单的冻结归零缺少资金流向解释；同一节点缺少正式时段锁，存在重叠承诺风险；现有“托管节点”也没有停止新接单、七天等待和清空未来订单后自动下架的规则。

## What Changes

- 将商品审核改为证据聚合视图，显示商品全部图片、关联 GPU 资质图片、供应方、规格、价格、SLA 与不可变提交版本。
- 增加覆盖实名认证、供应方、GPU 资质、商品和大额转让的审核记录页，按状态着色并显示审核人、结果、原因和时间。
- 为已支付 GPU 订单增加订单内文字/图片聊天、未读提醒、不可删除系统消息和结构化排期提议/确认。
- 将 GPU 固定套餐新订单改为“冻结卡时后协商排期”，只有双方确认且服务端锁定无冲突时段后才能交付；协商超时自动取消并解冻。
- 在租赁订单中展示原冻结、当前担保、已结算和已退回四个口径及完整资金时间线。
- 将顶部“我的订单”改为“租赁订单”，删除“我的资产”中的重复租赁页签，并在同一页面提供我购买的/我出租的筛选。
- 将现有“我的托管节点”升级为算力托管：持续上架、运行中仍可预约未来时段、订单结束自动恢复可预约、卖家下架申请立即停止新接单，并在申请满七天且所有订单/争议清空后自动下架。
- 新消息在客户端运行或处于后台时触发站内红点和本地通知；移动端真正离线推送不在本期范围。

## Capabilities

### New Capabilities

- `compute-hosted-marketplace-client`: 规定审核证据、订单聊天、排期、租赁订单资金视图和算力托管在桌面、Web、iOS、Android 共享界面中的行为。

### Modified Capabilities

无。

## Impact

- 影响算力中心 API 类型/调用、React Query 缓存、管理员审核、租赁订单、通知、我的设备和共享响应式页面。
- 依赖 `D:/watt/kod-ai-portal` 配套变更 `enhance-compute-hosted-marketplace` 提供审核快照、聊天、排期锁、担保投影和下架调度接口。
- 不改变官网人民币钱包、充值、零售站/节点切换、对话、生图、生视频和 Token 套餐 Key 的现有业务路径。
- 客户端不得自行推断资金结算或排期成功；所有权威状态均来自后端。
