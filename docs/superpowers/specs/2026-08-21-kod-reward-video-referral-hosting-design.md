# KOD 奖励、视频生成与卡时托管客户端设计

## 范围

本设计覆盖四个闭环：AI 视频生成框架、看广告奖励卡时、邀请好友奖励卡时、平台服务器月租后上架销售。实时行情明确不在本次范围，后续通过同事分支合并。

## 统一资产语义

客户端展示总卡时、可回购卡时、奖励卡时。广告和邀请所得均进入奖励卡时；奖励卡时可用于平台普通算力和 API 消费，但不能平台回购成人民币，也不能支付平台服务器月租。普通消费优先扣奖励卡时，再扣可回购卡时。回购页和服务器月租页只展示服务端返回的可用额度，不在客户端推算资格。

## AI 视频生成

保留现有生成视频入口、本地历史、任务进度、失败重试和下载体验。客户端只调用 KOD 后端的 availability、submit、status、content 接口，不接收、保存或编译上游 API Key。后端未配置 Key 时显示明确的不可用提示；配置完成后沿用现有任务闭环。

## 看广告得卡时

广告入口展示后台返回的活动素材。初始素材为用户提供的 `kod广告.mp4`，后续素材、海报、时长和启停状态均可由后台替换。每个账号按 `Asia/Shanghai` 自然日最多领取一次，每次固定 10 奖励卡时。完整播放并成功领取后弹窗显示“10 卡时已到账”，同时刷新卡时资产。重复请求、跨设备请求和未完整播放不得重复到账。

## 邀请好友

左侧侧边栏新增与“我的搭档 / 算力中心 / 设置”同级的“邀请好友”入口，原资产页内嵌返佣卡片移除。默认弹窗参考 Codex 邀请样式，支持输入邮箱、发送邀请记录、复制专属注册链接和进入“跟踪邀请”。输入邮箱不会发送邮件，只创建唯一待处理记录。

跟踪视图默认显示近 90 天记录，展示邮箱头像、邮箱和状态。`PENDING` 使用灰色“待处理”，`ACCEPTED` 使用绿色“已接受”；失败或失效状态使用红色并提供可理解原因。被邀请邮箱通过专属链接或邀请码首次注册并验证邮箱后，记录原子切换为 `ACCEPTED`，邀请人获得 10 奖励卡时并收到到账提示。同一邮箱、同一新用户只能绑定一个邀请人，不能补绑、改绑、自邀或重复发奖。

## 卡时托管与命名

现有“算力托管”统一更名为“算力租赁”，表示普通算力购买/租赁。新增“卡时托管”用于平台服务器月租业务：用户从平台库存选择服务器 SKU，以可回购卡时支付一个月租金，成功后服务器进入用户名下并按平台统一销售价挂到算力市场。

自动续租默认开启并提供小开关。用户关闭后当前租期不受影响，到期不再扣款；续租扣款失败或已关闭时立即停止接新订单，已有订单继续履约，全部结束后自动下架并释放库存。销售收入进入可回购卡时。

## 错误与安全

所有奖励、注册匹配、余额分桶、回购资格、月租扣款、续租和统一价格均由服务端裁决。客户端写操作携带稳定幂等键；超时后先刷新结果，不盲目重试。界面不得把总卡时误称为可回购卡时，也不得暗示奖励卡时能够变现。

## 测试

契约测试覆盖新余额字段、广告每日状态、邀请状态、月租与续租 DTO。组件测试覆盖广告到账弹窗、邀请输入/跟踪状态颜色、侧边栏入口、资产分桶、回购/月租额度和命名迁移。端到端契约测试覆盖注册接受邀请、重复领取、跨设备每日限制、奖励资产回购拒绝、奖励资产月租拒绝、续租关闭和余额不足下架。
